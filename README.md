# 拾账

个人使用的 Android 记账 App：主动导入支付详情或多笔账单列表截图，手机本地识别、分类，清楚的自动入账，缺失、模糊或疑似重复的先确认。支持手动补录、编辑删除、月度统计和账本问答。

首个验收设备为 **小米 15**，最低 **Android 12**。当前版本为 `0.2.4-screenshot`，包名沿用 `com.xixi.accounting`。实时采集已退出主流程，应用不再注册通知监听或无障碍服务。

## 使用

1. 在「账本」点击「导入账单截图」，或从相册分享图片到「拾账」。一次最多 10 张。
2. 截图只有月日时默认按当年导入，可修改默认年份；截图显示完整年份时保留原年份。
3. 查看识别结果。「待确认」可补全日期金额、修改分类、比对疑似重复记录后入账，也可以放弃。
4. 在「统计」查看月度收入、支出、退款、净支出和分类支出；在「查账」问“这个月餐饮花了多少”“上周有哪些退款”等问题，查看计算结果和对应明细。

完整安装及验收步骤见 [截图版验证说明](docs/screenshot-validation.md)。

## 记账规则

- 人民币金额用整数分保存，缺失金额为空；不推测截图遮挡的金额，不用日合计倒推明细。
- 按日期分组逐笔识别，日合计、余额和界面按钮不另行入账。支持主动导入历史账单截图。
- 保留截图中明确的分类；未知用途归“其他”。核对时默认记住商户分类，可取消；已有账单中同商户的分类一致时也可沿用。匹配忽略空白和全半角差异，应用于之后的“其他”记录。
- 同一图片重复导入直接提示；可靠交易号相同且内容一致时跳过；内容冲突或不同截图疑似重叠的交易进入待确认。不仅凭同金额删记录。
- 退款抵扣消费，不作为普通收入；内部转账不计入收入和消费统计。不会猜测退款对应哪笔原消费。
- 只有正式入账的账单计入统计和查账，列表、统计与问答采用相同口径。

## 查账与隐私

本地查账支持单一日期范围、分类、商户、方向或类型的明细、汇总、笔数和最大一笔。每次问题独立，不隐含沿用上一问的条件；复杂比较应分次查询。无法理解或日期不明确时提示补充条件。

可在「设置」中自行填写 DeepSeek API 密钥并开启可选的问题理解。默认关闭，常用查询不需要密钥。开启后仅在本地无法理解时发送当次问题、日期和分类选项，不发送图片或整本账本。用户在问题中写入的商户或金额也会随该问题发送。密钥通过 Android Keystore 加密保存在本机。

模型只能提出经过校验的只读筛选条件，不能执行 SQL、写入账单或操作微信。程序从本地正式账本计算金额并列出明细。没有记录表示该范围没有已导入记录，不表示现实中没有消费。账本编辑与删除通过界面明确确认。

图片识别后释放，不自动复制原图到长期存储。账单、候选、导入记录、商户规则、旧诊断和密钥可从设置中清除；相册原图保留。账本与密钥不自动云备份或迁移。真实微信原文、图片、设备导出和密钥不提交 Git。

## 开发

Kotlin、Jetpack Compose、Material 3、本地中文 ML Kit OCR、Room。界面使用暖白、沙色、琥珀色和深棕文字，包含定制透明插画、紧凑排版、环图和轻量过渡；视觉规范与资产提示词见 [UI 设计记录](docs/ui-design.md)。JDK 17、Android SDK 36、Gradle 8.11.1。

```powershell
./scripts/build.ps1                # 单元/集成测试、lint、debug APK
./scripts/build.ps1 -TestsOnly     # 仅测试
./scripts/build.ps1 -Offline       # 已缓存依赖时离线构建
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。本机工具链、Gradle 缓存、调试签名在被忽略的 `.tools/` 下；保留原签名才能覆盖更新旧版本。SDK 配置在被忽略的 `local.properties` 中。首次运行 Robolectric 测试另需下载 Android 测试运行时，不能仅凭 Gradle 依赖缓存假定完全离线可运行。

开发遵循已确认的三条公开行为边界：截图识别结果到候选或入账、确认或编辑到账本与统计、聊天问题到只读查询结果。持久化验证使用 Robolectric 的测试数据库，不等同于手机实测。

新方案见 [截图记账方案](docs/screenshot-import.md)，上下文见 [交接](HANDOFF.md)，规则见 [AGENTS.md](AGENTS.md) 和 [术语表](GLOSSARY.md)。原 [V1 采集规格](docs/spec-v1.md)、[实测记录](docs/device-validation.md) 和 [GitHub 任务关系](docs/agents/issue-tracker.md) 保留历史事实；实时采集不再作为截图版开发前置条件，未取得的设备验证不标记成功。

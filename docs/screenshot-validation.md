# 截图版安装与验收

版本 `0.2.4-screenshot`（versionCode 7），包名 `com.xixi.accounting`，Android 12+。

## 安装与首次使用

1. 将构建产物 `app/build/outputs/apk/debug/app-debug.apk` 传到手机安装；覆盖旧版时使用相同签名，不必卸载。显示名称为“拾账”，桌面与启动画面使用暖金色票据图标。检查圆形、圆角图标下图案完整；Android 13+ 可用时检查主题图标。
2. 无需授予通知监听或无障碍。新版已移除这两个服务入口；旧版候选保留为诊断，不会自动当作正式账单。
3. 进入「账本」选择截图，也可从相册分享图片到本 App。应用只读取你主动选择的图片；单次最多 10 张，单张最多 32 MB，特别长的图片建议分段。
4. 截图只有月日时默认使用当年，可修改默认年份；留空也使用当年。截图里已有完整年份时以截图为准。
5. 等待本地识别完成，查看已入账与待确认数量。无法识别或保存的图片会报告失败数量，可重试或手动补录。OCR 不保证覆盖所有布局；请核对结果。
6. 在「待确认」补全字段、核对完成状态、处理疑似重复；勾选确认独立交易后才能保存相关重复候选。放弃候选不计入统计。

## 本地查账

可试：“这个月餐饮花了多少”“昨天的支出明细”“上周有哪些退款”“全部账单最大一笔支出”“本月商户：示例书店的消费明细”。

每次写完整条件。指定“全部”可查询所有日期；未写年份的中文月份按当前年解释，结果显示完整日期范围。查询仅包含已导入且正式入账的记录。统计和回答随账本修改更新。

## 可选联网理解

默认关闭，本地识别、记账、统计和常用查账不需要密钥。在手机设置页填写自己的 DeepSeek 密钥，点击加密保存并开启“允许联网理解查账问题”。不要将密钥发送到聊天或提交源码。

联网理解只在本地不能理解问题时调用，发送本次问题和日期、分类选项；不发送图片或整本账本。模型返回的条件经过日期、字段和枚举校验，程序负责计算；异常时不会写入账本。真实服务调用、密钥保护及清除效果仍需手机验证。
